# Smart Community Connect

A frontend prototype of a centralized platform for residential communities, built with HTML5, CSS3 and vanilla JavaScript.

## Project Overview
Smart Community Connect brings issue reporting, polls, volunteering, announcements, feedback and management tools into one dashboard. Data is stored in the browser's `localStorage`, so no server is needed.

## Problem Statement
In many residential communities, communication between residents and management is fragmented across WhatsApp groups, phone calls, and verbal complaints. This makes it difficult to systematically report and track community issues, collect residents' opinions, organize volunteers, and encourage participation in community activities. A centralized software platform is needed that lets residents report and track issues, give feedback, take part in polls and activities, volunteer for local initiatives, and communicate effectively with management.

## Objectives
- Provide one place for community communication
- Let residents report issues and track their progress
- Collect opinions through polls and feedback
- Encourage participation in activities and volunteering
- Give management a simple overview and control panel

## Features
- **Dashboard** with live statistics, recent announcements and recent issues
- **Report Issue** form with validation and auto-generated issue IDs
- **Issue Tracking** with search, status/category/priority filters and progress bars
- **Polls** with one vote per browser and percentage results
- **Activities** with volunteer counts and join registration
- **Announcements** with an "Important" badge
- **Feedback** form with 1-5 rating
- **Management view** (Resident/Management toggle): change issue status, view feedback, poll results, volunteer participation, and reset demo data
- Responsive layout, mobile menu, toast notifications, modal dialogs

## Technologies Used
HTML5, CSS3, Vanilla JavaScript, localStorage (no frameworks, no backend, no build tools)
